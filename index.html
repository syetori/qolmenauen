Добавить свою MIDI-песню

Загрузите MIDI-файл, выберите дорожку с мелодией и добавьте её в игру.

MIDI — это файл с нотами и их временем, а не аудиозапись. По этим нотам сайт создаёт падающие жесты и играет выбранным инструментом. MP3 сюда не подходит.

MIDI читается локально. До 10 мелодий; данные сохраняются в этом браузере.

ВАШ РИСУНОК БОЯ

Один ритм. Любые аккорды.

Нажимайте на шаг: ↓ вниз → ↑ вверх → — пауза. Пауза занимает время; шаги за длиной цикла не играют.

Бой остановленГотов к запускуНастройка хранится на этом устройстве
🖐 🖐 → 🖐 ✊
Две ладони → один кулак = запуск / остановка

В режиме 7 аккордов покажите две открытые ладони, затем одну сожмите. Уберите вторую руку и выбирайте аккорды любой одной рукой. Перед повтором снова раскройте обе ладони. Нет рук — нет звука; ритм сохраняется.

Смена аккорда не сбрасывает ритм. Пробел — запуск / остановка боя, Esc — остановить всё. В режимах 35 аккордов и своих комбинаций используйте кнопку или пробел.

СЛОВАРЬ ДВИЖЕНИЙ

Семь жестов. Тысячи мелодий.

Зажмите карточку для прослушивания

Вторая рука меняет характер аккорда

Кулак → мажор · указательный → минор · указательный + средний → 7 · три пальца → maj7 · раскрытая ладонь → sus4. Обе руки должны быть в кадре. Например: левая указательный + правая указательный = Cm.

Если обозначения рук перепутаны в вашей камере, поменяйте этот параметр.

Создайте свою комбинацию

Выберите поднятые пальцы каждой руки. Ни одного пальца = кулак. «Не требуется» означает, что рука отсутствует в кадре.

01 / ПЕРВЫЙ АККОРД

Ладонь к камере

Начните с указательного пальца — это C. Кулак одной руки означает тишину. Можно использовать любую руку. Для запуска боя покажите две ладони и сожмите одну.

02 / ПЕРВАЯ МЕЛОДИЯ

C → G → Am → F

Указательный → пять пальцев → два пальца → четыре. В режиме боя держите жест до смены аккорда: рисунок продолжит играть без сброса ритма.

03 / БЫСТРЫЙ ОТКЛИК

Меньше движений

Камера работает в 640 × 480, кадры обрабатываются по одному. Уменьшайте подтверждение, если жесты распознаются стабильно.
