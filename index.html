Вторая рука меняет характер аккорда

Кулак → мажор · указательный → минор · указательный + средний → 7 · три пальца → maj7 · раскрытая ладонь → sus4. Обе руки должны быть в кадре. Например: левая указательный + правая указательный = Cm.

Если обозначения рук перепутаны в вашей камере, поменяйте этот параметр.

Создайте свою комбинацию

Выберите поднятые пальцы каждой руки. Ни одного пальца = кулак. «Не требуется» означает, что рука отсутствует в кадре.

01 / ПЕРВЫЙ АККОРД

Ладонь к камере

Начните с указательного пальца — это C. Кулак в простом режиме означает тишину. Можно использовать любую руку.

02 / ПЕРВАЯ МЕЛОДИЯ

C → G → Am → F

Указательный → пять пальцев → два пальца → четыре. Удерживайте каждый жест столько, сколько хотите слышать аккорд.

03 / БЫСТРЫЙ ОТКЛИК

Меньше движений

Камера работает в 640 × 480, кадры обрабатываются по одному. Уменьшайте подтверждение, если жесты распознаются стабильно.

01 / ЛИНИЯЩипок

Большой + указательный. Ведите рукой, чтобы рисовать.

02 / ЛАСТИКДва пальца вместе

Выпрямите указательный и средний и сведите их кончики.

03 / МАСШТАБДва щипка

Щипок обеими руками: разводите, сближайте или перемещайте руки. После разожмите оба щипка.

04 / ЦВЕТКулак

Держите полсекунды. Один кулак — один новый цвет. Раскройте ладонь перед повтором.

05 / КИСТЬБольшой вверх

Держите этот жест: вправо — толще, влево — тоньше. Вверх — прозрачнее, вниз — плотнее.
